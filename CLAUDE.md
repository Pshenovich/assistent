# Орбита / Лео — правила для агентов

## Техническое описание проекта

Полное техническое описание — документ «Техническое описание» в базе знаний Орбиты
(Obuchat AI › Продукты › Орбита, id **10000016**), доступен через MCP `orbita-kb`
(`read` с id 10000016). Перед заметной работой прочитай нужные разделы, особенно
16 «Правила и решения» и 17 «Известные расхождения».

## Обязательно после каждой выкатки на прод

Агент, который выкатил изменения (`scripts/deploy_prod_replace.sh` завершился успешно),
в той же сессии обновляет документ 10000016:

1. Прочитай документ (`orbita-kb` → `read`, id 10000016). В конце — раздел
   «Журнал выкаток»: последняя запись содержит коммит прошлой выкатки.
2. Посмотри, что уехало: `git log --oneline <коммит прошлой выкатки>..<коммит этой выкатки>`
   (коммит этой выкатки скрипт печатает в конце) и `git diff --stat` по тому же диапазону.
3. Если изменения меняют описанное в документе (новая функция, маршрут, флаг `.env`,
   интеграция, правило, хранилище, процесс выкатки, решение владельца) — исправь
   соответствующие разделы. Документ целиком переписывается через `update_doc` с
   `mode=replace` (бери текст из `read`, меняй только нужное). Мелкие правки
   (тексты, стили, багфиксы без новых правил) разделы не меняют.
4. Всегда добавь запись в «Журнал выкаток» (`update_doc`, `mode=append` можно, если
   журнал — последний раздел): дата UTC, коммит, 1–3 строки «что уехало», какие разделы
   документа поправлены (или «разделы не менялись»).
5. Не пиши в документ секреты (ключи, токены, пароли, ключи прокси в URL).

Если `orbita-kb` недоступен в сессии — скажи владельцу, что документ не обновлён,
и перечисли, что нужно поправить.
