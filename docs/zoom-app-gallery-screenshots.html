App Gallery Screenshot Checklist

Capture these screens with the test Telegram + Zoom accounts, then upload to Zoom Marketplace → App Submission → App Gallery. Recommended size: 1280×720 or 1920×1080 PNG.

  1. Home URL landing
    Open assistant.obuchat.me/zoom/home in a browser. Show title, bot link, and Mini App link.
  2. Telegram — Connect Zoom prompt
    In the test bot chat, show /zoom_auth or the Profile → Zoom → Connect button in Mini App before OAuth.
  3. Zoom OAuth consent
    Screenshot the Zoom permission screen listing meeting scopes (Production Client ID).
  4. Mini App — Zoom connected
    Profile → Zoom section showing connected name/email and Disconnect button.
  5. Instant meeting created
    Send zoom in Telegram; capture bot reply with join URL.
  6. Calendar event with Zoom link (optional if Google Calendar connected)
    Mini App calendar or Google Calendar event showing auto-attached Zoom link.
  7. Meeting recordings in Profile
    Mini App → Profile → Zoom recordings list (meeting-bot recordings; may be empty with caption explaining feature).
  8. Disconnect Zoom (optional)
    Profile → Zoom → Disconnect confirmation.

Minimum for resubmission: screenshots 1–5 and 7. Upload in Zoom Marketplace portal — images are not stored in this repository.
