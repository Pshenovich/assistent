Obuchat Assistant — Release Notes for App Review

Version submitted: July 2026 · Distribution: Unlisted · App type: User-managed OAuth (General app)

Summary

Obuchat Assistant is a Telegram bot and Mini App that helps users manage calendar events, reminders, and Zoom meetings from chat. The Zoom integration lets an authenticated user create instant or scheduled meetings, reschedule or delete meetings via natural language, attach Zoom links to Google Calendar events, view meeting-bot recording metadata in Profile, and disconnect Zoom from the Mini App or via Zoom account settings.

This is not a Zoom in-client app. There is no UI inside the Zoom meeting client. Users connect Zoom through OAuth initiated from Telegram (/zoom_auth) or Mini App → Profile → Zoom → Connect. After authorization, all Zoom API calls run server-side on behalf of the user who granted consent.

How to access the app (reviewer steps)

  1. Open Home URL: https://assistant.obuchat.me/zoom/home
  2. Click Open bot in Telegram → https://t.me/PshAssistent_bot
  3. Log in with test credentials from Marketplace Account Credentials (dedicated Telegram phone + Zoom email/password; test Telegram user pre-approved).
  4. Send /zoom_auth or open Mini App → Profile → Zoom → Connect and complete OAuth (Production Client ID).
  5. Test scopes using the steps in the Test Plan.

OAuth scopes requested (all required)

ScopePurpose
user:read:userDisplay connected Zoom account (name/email) in Mini App Profile.
user:read:tokenYes — note-taking agent: Leo joins the meeting via Zoom SDK (OBF) to record, transcribe, and summarize. Not used for ZAK.
meeting:write:meetingCreate instant meetings (zoom command) and scheduled meetings linked to calendar events.
meeting:read:list_meetingsList upcoming meetings (GET /users/me/meetings) so delete/reschedule can resolve the target, then call DELETE/PATCH.
meeting:update:meetingReschedule meetings via natural language (PATCH /meetings/{id}).
meeting:delete:meetingRemove Zoom meetings on user request (DELETE /meetings/{id}).

user:read:zak is not used and must not be selected. Meeting recordings in Profile come from our meeting-bot pipeline (Vexa), not the Zoom Cloud Recording API — cloud_recording:read:recording is not requested.

Webhooks & deauthorization

  • Event subscription URL: https://assistant.obuchat.me/webhook — meeting.ended (post-meeting notification).
  • Deauthorization URL: https://assistant.obuchat.me/webhook/deauthorize — on app_deauthorized, we delete stored OAuth tokens and Zoom profile metadata within 24 hours.
  • In-app disconnect: Mini App → Profile → Zoom → Disconnect (revokes token at Zoom and deletes local credentials).

Data handling & security

  • All traffic over HTTPS (TLS 1.2+). OAuth tokens stored server-side with restricted file permissions (chmod 600).
  • Secrets (client secret, webhook secret) are in server environment variables only — not in client-side code.

Known limitations
