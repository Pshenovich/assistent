Ассистент бронирования

Что это

Отдельный Telegram-аккаунт пишет менеджерам ресторанов от вашего имени. Ваш личный аккаунт и серверный ассистент владельца не используются.

Шаг 1 — API на my.telegram.org

Войдите на my.telegram.org → API development tools → создайте приложение (название любое). Скопируйте api_id и api_hash сюда. Обычно достаточно войти с основного номера; сессию ниже создаёте уже для отдельного аккаунта ассистента.

Шаг 2 — отдельный аккаунт

Зарегистрируйте второй номер в Telegram (или используйте запасной). Именно с этим номером на шаге 3 придёт код входа. Этот аккаунт будет писать ресторанам.

Шаг 3 — вход ассистента

WhatsApp (рестораны по телефону)

Отдельный номер с WhatsApp. В приложении WhatsApp: Связанные устройства → привязать по QR. Если у заведения есть телефон, ассистент напишет в WhatsApp.
